## API 화면 규칙의 이유
규칙 본문은 CLAUDE.md에 있다. 여기에는 규칙이 왜 있는지만 적는다.
- 키 없는 API만: HTML은 누구나 코드를 볼 수 있어서 키가 새어 나감
- `// 🔌` 표시: 어디가 API인지 바로 찾으려고
- API 상자: 주소를 바꾸면 주문이 바뀌는 걸 눈으로 보려고
- 카드별 로딩·실패: 무료 API는 멈추거나 바뀜
- 출처·기준 날짜: API 규칙이 출처 표기를 요청함. 환율은 하루 한 번 발표되는 기준값
- HTML 한 파일: 설치 없이 바로 확인하려고
- 커밋·푸시 금지: 세이브 포인트는 내가 검사한 뒤에 찍음
